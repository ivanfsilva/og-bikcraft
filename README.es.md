# 🚲 Bikcraft — UI Design & Design System

Este repositorio contiene el proyecto visual y la arquitectura de interfaz de **Bikcraft**, una marca ficticia de bicicletas eléctricas artesanales de alto rendimiento, desarrollada como proyecto integrador principal en el curso de **UI Design** de **Origamid**. El objetivo del proyecto es construir un Design System sólido, definiendo la identidad visual, jerarquía tipográfica, paleta de colores funcional, componentes reutilizables y la composición visual de las 7 páginas de la aplicación en Figma, sentando las bases para la futura implementación frontend.

---

## 🎯 Sobre el Proyecto y Conceptos Clave

**Bikcraft** fue diseñado para ofrecer una experiencia de compra y navegación fluida, premium y accesible para entusiastas del ciclismo y la movilidad urbana.

- **Arquitectura de Páginas (7 Páginas):**
  - **Home:** Presentación de la marca, modelos destacados, diferenciales y testimonios.
  - **Bicicletas:** Catálogo completo de modelos (Magic, Nimbus, Nebula).
  - **Detalle de Bicicleta:** Especificaciones técnicas, características y galería interactiva del producto.
  - **Seguros:** Planes de protección (Plata y Oro) y cobertura detallada.
  - **Contacto:** Información institucional, mapa de localización y soporte.
  - **Términos:** Reglamento, políticas de privacidad y términos de uso.
  - **Presupuesto:** Formulario dinámico para solicitud de propuesta personalizada.

- **Design System & Toma de Decisiones Visuales (Figma):**
  - **UI Kit Completo:** Estandarización de botones, inputs, cards, íconos, encabezados y pie de página.
  - **Grid Rítmico y Espaciado:** Aplicación rigurosa de sistemas de retícula y escalas proporcionales.
  - **Tipografía y Colores:** Uso estratégico de la paleta de colores (destacados en amarillo/negro), contraste accesible y fuentes jerarquizadas.

- **Estructura y Codificación Web (Frontend Future Release):**
  - Estructuración semántica en HTML5 para optimización SEO y accesibilidad (a11y).
  - Estilizado avanzado con CSS3 (Variables, Flexbox y CSS Grid).
  - Funcionalidades en JavaScript puro (galería, acordeón de preguntas frecuentes e interacciones en formularios).
