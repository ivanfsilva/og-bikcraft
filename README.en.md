# 🚲 Bikcraft — UI Design & Design System

This repository contains the visual project and interface architecture for **Bikcraft**, a fictional brand of handcrafted, high-performance electric bicycles, developed as the main capstone project in **Origamid**'s **UI Design** course. The goal of this project is to build a robust Design System by defining the visual identity, typographic hierarchy, functional color palette, reusable components, and visual composition for all 7 application pages in Figma, establishing the foundation for future frontend implementation.

---

## 🎯 About the Project & Key Concepts

**Bikcraft** was designed to offer a seamless, premium, and accessible purchasing and browsing experience for cycling and urban mobility enthusiasts.

- **Page Architecture (7 Pages):**
  - **Home:** Brand introduction, featured models, key differentiators, and testimonials.
  - **Bicycles:** Complete catalog of models (Magic, Nimbus, Nebula).
  - **Bicycle Details:** Technical specifications, features, and interactive product gallery.
  - **Insurance:** Protection plans (Silver and Gold) and detailed coverage.
  - **Contact:** Institutional information, location map, and support.
  - **Terms:** Regulations, privacy policy, and terms of service.
  - **Quote:** Dynamic form for custom proposal requests.

- **Design System & Visual Decision Making (Figma):**
  - **Complete UI Kit:** Standardization of buttons, inputs, cards, icons, headers, and footers.
  - **Rhythmic Grid & Spacing:** Strict application of layout grid systems and proportional scales.
  - **Typography & Colors:** Strategic use of color palette (yellow/black highlights), accessible contrast, and hierarchical fonts.

- **Structure & Web Coding (Frontend Future Release):**
  - Semantic HTML5 structuring for SEO optimization and accessibility (a11y).
  - Advanced CSS3 styling (Variables, Flexbox, and CSS Grid).
  - Vanilla JavaScript functionalities (gallery, FAQ accordion, and form interactions).
