# 🚲 Bikcraft — UI Design & Design System

Este repositório contém o projeto visual e a arquitetura de interface da **Bikcraft**, uma marca fictícia de bicicletas elétricas artesanais desenvolvida como projeto principal integrador no treinamento de **UI Design** da **Origamid**. O objetivo do projeto é construir um Design System robusto, definindo a identidade visual, hierarquia tipográfica, paleta de cores funcional, componentes reutilizáveis e composição visual das 7 páginas da aplicação no Figma, estruturando a base para a futura implementação frontend.

---

## 🎯 Sobre o Projeto e Conceitos-Chave

O **Bikcraft** foi planejado para oferecer uma experiência de compra e navegação fluida, premium e acessível para entusiastas de ciclismo e mobilidade urbana.

- **Arquitetura de Telas (7 Páginas):**
  - **Home:** Apresentação da marca, modelos em destaque, diferenciais e depoimentos.
  - **Bicicletas:** Catálogo completo dos modelos (Magic, Nimbus, Nebula).
  - **Bicicleta Interna:** Detalhes técnicos, especificações e galeria interativa do produto.
  - **Seguros:** Planos de proteção (Prata e Ouro) e cobertura detalhada.
  - **Contato:** Informações institucionais, mapa de localização e suporte.
  - **Termos:** Regulamento, políticas de privacidade e termos de uso.
  - **Orçamento:** Formulário dinâmico para solicitação de proposta personalizada.

- **Design System & Tomada de Decisão Visual (Figma):**
  - **UI Kit Completo:** Padronização de botões, inputs, cards, ícones, cabeçalho e rodapé.
  - **Grid Rítmico & Espaçamentos:** Aplicação rigorosa de sistemas de grid e escalas proporcionais.
  - **Tipografia e Cores:** Uso estratégico da paleta de cores (destaque amarelo/preto), contraste acessível e fontes hierarquizadas.

- **Estrutura e Codificação Web (Frontend Future Release):**
  - Estruturação semântica em HTML5 para otimização de SEO e acessibilidade (a11y).
  - Estilização avançada com CSS3 (Variáveis, Flexbox e CSS Grid).
  - Funcionalidades em JavaScript puro (galeria, acordeão de dúvidas e interações do formulário).
